# ROBO-IADesign Thinking – Proyecto ROBO-IA
1. EMPATIZAR
¿Qué quiero hacer?

Quiero desarrollar un robot inteligente llamado ROBO-IA, capaz de interactuar con las personas mediante la voz, reconocer lo que dicen, responder, aprender información nueva y expresar diferentes emociones mediante un rostro animado.

La idea es que la interacción con el robot sea más natural y sencilla, permitiendo que una persona pueda comunicarse con él de una manera similar a una conversación.

¿A quién ayudo?

El proyecto está pensado principalmente para estudiantes, docentes y personas interesadas en la tecnología y la inteligencia artificial.

ROBO-IA puede servir como una herramienta educativa para aprender sobre:

Inteligencia artificial.
Programación.
Reconocimiento de voz.
Aprendizaje automático.
Robótica.
Interacción humano-computadora.
¿Cuál es el motivo que nos mueve?

El motivo principal es crear una herramienta tecnológica que permita aprender y experimentar con inteligencia artificial de una manera práctica.

También nos motiva demostrar que es posible construir un sistema inteligente utilizando herramientas accesibles y conocimientos de programación, haciendo que la tecnología no sea solamente algo que utilizamos, sino algo que podemos crear, modificar y mejorar.

2.  DEFINIR

En esta etapa se analiza la información obtenida durante la empatía y se identifica el problema principal que realmente queremos solucionar.

Problema identificado

Muchas veces el aprendizaje de programación, inteligencia artificial y robótica se realiza solamente de forma teórica. Esto puede dificultar que los estudiantes comprendan cómo funcionan estas tecnologías en situaciones reales.

Además, los sistemas tecnológicos tradicionales no siempre ofrecen una interacción visual y auditiva que resulte atractiva para el usuario.

Necesidad

Se necesita una herramienta que permita aprender y experimentar con inteligencia artificial mediante una interacción práctica, visual y por voz.

Problema definido

¿Cómo podemos crear un robot inteligente que permita a las personas interactuar mediante la voz y, al mismo tiempo, aprender sobre programación, inteligencia artificial y robótica de una manera práctica y atractiva?

A partir de esta pregunta surge la propuesta de ROBO-IA.

3.  IDEAR
En esta etapa se deja fluir la imaginación para generar diferentes soluciones posibles al problema identificado.

Se plantearon varias ideas:

Crear un robot capaz de escuchar mediante un micrófono.
Utilizar Whisper para convertir la voz en texto.
Crear un sistema que pueda responder a las preguntas del usuario.
Incorporar una memoria permanente para guardar conocimientos.
Crear un modo de aprendizaje para que el robot pueda incorporar nueva información.
Crear un modo profesor para realizar preguntas y comprobar respuestas.
Incorporar diferentes emociones.
Crear un rostro animado mediante Tkinter Canvas.
Hacer que los ojos y expresiones del robot cambien según lo que está haciendo.
Incorporar comandos relacionados con movimientos del robot.
Permitir que el sistema pueda seguir desarrollándose en futuras versiones.
Solución propuesta

Después de analizar las diferentes ideas, se propone desarrollar ROBO-IA, un sistema que combine:

Voz →  Inteligencia →  Memoria → Emociones → Interacción

De esta manera, el robot no solamente recibe información, sino que puede escuchar, procesar, responder, aprender y expresar estados mediante su rostro.

4.  PROTOTIPAR

Se construye una primera versión funcional de la solución.
En ROBO-IA, el prototipo incluye:
Python como lenguaje principal.
Whisper BASE para reconocimiento de voz.
Sistema de memoria permanente.
Modo aprendizaje.
Modo profesor.
Sistema de emociones.
Rostro animado.
Interacción mediante micrófono.
Respuestas del robot.
5.EVALUAR / TESTEAR

Se prueba el prototipo con diferentes situaciones para comprobar su funcionamiento.

Por ejemplo:

Prueba	Resultado esperado
Decir "Hola ROBO-IA"	El robot reconoce el saludo y responde
Hacer una pregunta	El robot procesa la voz y responde
Enseñarle información	Guarda el conocimiento
Preguntar algo aprendido	Recupera la información
Activar modo profesor	Realiza preguntas
Hablar mientras escucha	Muestra emoción de atención
Pensar una respuesta	Muestra expresión de pensamiento
Responder correctamente	Muestra felicidad
No comprender	Muestra confusión
Resultado del proceso

El Design Thinking permite pasar de una necesidad o problema a una solución tecnológica concreta:

EMPATIZAR
Comprender la necesidad de una herramienta educativa e interactiva.

DEFINIR
Identificar la necesidad de un sistema que facilite la interacción y el aprendizaje de IA.

IDEAR
Generar diferentes ideas para solucionar el problema.

PROTOTIPAR
Construir ROBO-IA.

TESTEAR
Probar sus funciones y realizar mejoras.

ROBO-IA
Un proyecto que combina programación, inteligencia artificial, reconocimiento de voz, memoria y expresiones visuales para crear una experiencia de interacción más práctica y educativa.
